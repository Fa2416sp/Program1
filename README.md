# Program1

## Описание
**Program1** - это консольное приложение на C#, которое выполняет вычисления на основе введенных пользователем целых и действительных чисел.

## Как использовать
1. Склонируйте репозиторий:
    ```bash
    git clone https://github.com/Fa2416sp/Program1/
    ```
2. Перейдите в директорию проекта:
    ```bash
    cd Program1
    ```
3. Соберите проект:
    ```bash
    dotnet build
    ```
4. Запустите приложение:
    ```bash
    dotnet run
    ```

## Пример использования
После запуска программы, вам будет предложено ввести три целых числа (i1, i2, i3) и три действительных числа (d1, d2, d3). Программа выполнит вычисления и выведет результаты X, Y и Z.

Пример ввода:
i1 = 5 i2 = 10 i3 = 15 d1 = 1.5 d2 = 2.5 d3 = 3.5

Пример вывода:
Результаты: X = 8.583 Y = 0.600 Z = 1.7500
